## CHFI-ELTMRF

This repository provides the MATLAB implementation of the Change Homogenizing Flood Index (CHFI) and the Expedited Locally Tuned Markov Random Field (ELTMRF) approach developed for unsupervised floodwater detection from bi-temporal Sentinel-1 SAR imagery.

The proposed approach combines a new flood-change index with a locally tuned MRF model to improve the representation and segmentation of flood-related changes. CHFI is designed to reduce the heterogeneity of flood-change patterns caused by variations in reference backscatter, while ELTMRF partitions the resulting change information into flood and non-flood classes with particular attention to boundary preservation and computational efficiency.

### A) Method Overview

The proposed flood detection framework consists of two main stages.

1. Change Homogenizing Flood Index (CHFI)

CHFI is formed by combining complementary flood-change information derived from the pre- and post-flood Sentinel-1 SAR images. A key component of CHFI is the Flood-Change Homogenizing Regulator (FCHR), which is designed to mitigate the dependency of flood-change magnitude on reference backscatter and thereby reduce the heterogeneity of flood-related changes.

2. Expedited Locally Tuned MRF (ELTMRF)

The resulting CHFI is subsequently segmented using ELTMRF. The model locally tunes spatial context to distinguish flood and non-flood areas while reducing excessive smoothing along meaningful flood boundaries. A blockwise processing strategy is also employed to improve computational efficiency.

The final output is a binary flood extent map separating flooded and non-flooded areas.

### B) Repository Contents

The repository contains the following MATLAB files:

-RunTheModule.m: Main script for selecting a dataset, loading the required inputs, running the proposed CHFI-ELTMRF approach, and reporting the runtime.

-CHFI_ELTMRF.p: MATLAB P-code implementation of the complete CHFI-ELTMRF flood detection approach.

-CHFI.p: MATLAB P-code implementation of the proposed CHFI module.

The main implementation files are provided in MATLAB P-code format.

### C) Input Data

For each study area, the following GeoTIFF files are used:

PreFlood-[Name].tif

PostFlood-[Name].tif

PWmask-[Name].tif

GroundTruth-[Name].tif

where [Name] represents the name of the selected study area.

The files correspond to:

PreFlood-[Name].tif: Sentinel-1 SAR image acquired before the flood event.

PostFlood-[Name].tif: Sentinel-1 SAR image acquired during/after the flood event.

PWmask-[Name].tif: Permanent-water mask representing surface-water areas existing before the flood event.

GroundTruth-[Name].tif: Reference flood map associated with the selected dataset.

The pre- and post-flood SAR amplitude images in linear scale and the permanent-water mask are used as inputs to the CHFI-ELTMRF implementation.

### D) How to Run

Place the required input files in the MATLAB working directory together with the repository files.
Open RunTheModule.m and specify the study area by changing the value of Name. For example:
Name = 'Bavi';

The script automatically reads the corresponding files:

PWmask = imread(['PWmask-',Name,'.tif']);

I1L = double(imread(['PreFlood-',Name,'.tif']));

I2L = double(imread(['PostFlood-',Name,'.tif']));

Test = single(imread(['GroundTruth-',Name,'.tif']));

The proposed approach is then executed using:

ELTMRFLabel = CHFI_ELTMRF(I1L,I2L,PWmask);

To run the experiment, simply execute:
RunTheModule

### E) Outputs

After execution, the main output variables are:

ELTMRFLabel: Flood extent map generated by the proposed CHFI-ELTMRF approach.

Runtime: Computational time required for generating the flood map, reported in seconds.
